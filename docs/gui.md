# 成员 C：界面、线程与验收

关联 [Issue #3](https://github.com/We1chan/campus-print-scheduler/issues/3)。

## 当前可运行功能

两台打印机分别显示文档、尝试状态与页数进度；任务表按 `job_id` 关联，支持等待/运行/完成/失败/取消筛选。
进度到 100% 不提前标为成功：必须收到输出提交与监督完成事件、监督进程正常退出 0，且最终输出文件存在。
重试从 0 显示新尝试；无效事件只记诊断，不修改任务状态。

可切换 FCFS、SJF、优先级老化（30 秒增加 1 点；基础优先级越大越优先）。
暂停仅影响新任务领取。等待任务可以立即取消，运行任务继续执行。
统计直接使用 A 的 `statistics()`，显示本次会话的首次等待、成功任务周转、吞吐量、利用率与状态计数柱状图；
空样本均值显示 0，结合图中的样本数量解读。导出 JSON 报表在工作线程原子写入。
会话允许中途切换策略，因此该报表不能作为同负载策略对比；正式算法对比使用 `scheduler-replay`。

## 线程和消息分帧

`PrintWindow`/`JobTableModel` 在 GUI 线程。`PrintController` 移到专用 QThread，之后在该线程创建
QProcess 和定时器，处理调度、文件写入、JSON 导入、日志解析及统计。显式 `Qt::QueuedConnection`
传递值快照与信号，不跨线程持有或修改 QWidget。

每个 supervisor stdout 使用独立 `EventStream`：先缓存字节、按 LF 组完整行、再解码 JSON。
支持 CRLF、空行、UTF-8 多字节拆分和多行合并。校验 schema_version、job_id、事件类型及进度范围。
单帧上限 64 KiB，超限丢弃到下个换行后继续；连接结束的半条消息记错误。stderr 为有界诊断文本。

后台每 100 ms 发一次任务/统计快照，每批最多 200 条日志；前台日志最多保留 500 行。
任务表使用 model/view 和增量行通知，保留选择，不为每个单元格创建 QWidget。
关闭请求也排队交给后台确认，防止“刚点击提交、界面尚未刷新就关闭”的竞态。

## 批量输入

使用 [gui-batch.json](../examples/gui-batch.json) 的非空 JSON 数组，字段为 title、pages、copies（默认 1）、priority（默认 0）。
整个文件先校验，非法行不会导致部分导入；文件上限 4 MiB，会话最多 10000 个任务。
导入时生成新 ID 并立即入队，不保留回放文件的模拟到达时间。
需要比较策略时先暂停，导入相同输入，再选择策略并继续派发。

## B 接口依赖（尚未完成的部分）

当前主仓库只有按单个任务启动的 supervisor v1，没有持久服务连接、取消确认或故障控制命令。

| 功能 | 当前行为 | 接入条件 |
| --- | --- | --- |
| 等待任务取消 | 已接 A 的 cancel | 无额外依赖 |
| 运行中取消 | 禁用并提示原因 | B 停止执行并提供 attempt 的确认后，才能调用 acknowledgeCancel |
| 执行器缺失 | 显示不可用，允许重新检查，保留等待队列 | 已支持现有独立进程布局 |
| 服务断线重连 | 明示接口待接入 | B 的连接/重连、状态快照、事件版本与执行令牌 |
| 故障注入 | 默认隐藏，`--demo-mode` 中禁用并解释 | B 受控故障命令；不能靠杀 supervisor 冒充 |
| 应用重启恢复 | 未实现，界面明确提示 | B 的持久服务与重启对账 |

未伪造服务连接或成功的取消确认，也未修改 B 的进程与存储模块。B 合入接口后，保持 GUI 信号层，
在控制器接入真实服务事件与控制确认，并补断线、重连、取消/成功竞争及旧 attempt 回调测试。

## 验收步骤

1. 启动 `campus-print --data-dir runtime/gui`，暂停派发，导入示例，然后继续：看到两台打印机的独立进度与等待队列。
2. 暂停新任务派发，选中等待任务取消，再继续；运行任务取消按钮保持禁用。
3. 提交空白名称或总页数超过 10000 的任务，看到错误且队列不增加。
4. 按开发文档结束事件日志中本任务的 worker PID，观察恢复状态、进度归零与最终结果。
5. 导出统计 JSON；将输出目录设为不可写时观察失败反馈，不能把进度满格当成功。
6. CTest `gui` 自动覆盖任意字节拆包、粘包、非法版本/ID/字段、超长帧恢复、真实提交/取消/完成和 5000 项队列交互。
