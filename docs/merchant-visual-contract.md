# 店主端视觉与实现约定

分支 `feat/merchant-editorial`，工作树 `campus-print-merchant`，基线为学生端已提交的 `42f77a1`，不修改学生端工作树。学生/店主复用现有 controller/coordinator 协议。

四张经用户确认的 1586 × 992 概念图是本次视觉基准。原生 Qt 以这个坐标系绘制可交互、数据驱动的控件，按窗口尺寸缩放；不能以整张截图作为页面或用图片代替功能。

共同几何：顶栏 y0–56；主区 x0–1145；详情 x1145–1586；页脚主操作 y862–942；状态 y942–992。白纸、墨蓝 #0B1B3B、朱红 #D93E29；中文衬线大标题，微软雅黑正文。照片/纸张素材可以从确认的概念图中按源矩形绘制，界面文字、表格、图表、进度与按钮必须真实绘制。

分工：主代理管理共用 painter、窗口/入口、资源、构建和截图核对；独立子任务负责 workbench/queue 绘制、devices/stats 绘制、数据映射与命令。所有绘制只使用 merchant_painter.hpp 合同，各自文件独占。

默认店主入口连接真实的本地持久后台；`--merchant-showcase` 是明确的本地样例数据模式，供概念图比对与交互演示。状态区明确标示样例，不伪装实际订单。源文件内容传输与物理打印仍沿用现有系统边界。
