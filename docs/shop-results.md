# 经营调度实验结果

历史结果说明：下文是旧优先级/期限/收入策略版本的实际记录，原数值保留。2026-10-10 起程序仅运行 FCFS、SJF、综合调度，且设备分配已拆成第二层；这些旧表不能作为新版结果，原命令需配合当时的程序版本复现。新版规则和实验入口见 [两层调度](scheduling.md)。

本次结果来自 2026-09-23 本地实际运行：固定种子 `20260923`，600 名潜在客户，6 台异构设备，8 小时营业窗口。所有需求、预算、价格与成本均为模拟假设。

命令：`./build/dev/bin/shop-experiments --customers 600 --seed 20260923 --hours 8 --output runtime/shop-evidence/experiments.json`。摘要保存在 [shop-summary.json](../experiments/shop-summary.json)，完整原始报表可用该命令重建。

## 2026-10-01：本地大学文档负载复测

在本机 Windows / MinGW / Qt 环境实际执行，使用本地去重后的 668 份大学资料，共 1,087,775,936 字节。PDF 246 份读取页树，PPTX 75 份读取幻灯片清单；225 份使用 Office 保存的分页统计，121 份按文本或表格规则估计，1 份旧 DOC 无法识别容器，明确按大小回退为 1 页。一个 XLS 估算 13,097 页，按调度模型的单文档上限截到 1000 页；最终负载为 15,664 页单位。

每份文件对应一个匿名订单。打印规格、优先级、服务档位和到达时间由文件 SHA-256 确定，**不是实际打印记录**。设备使用生产版六台异构打印机及计价规则，库存充足，无故障、无实际文件打印、无下单后流失。三种场景为：

- 全天：668 单在前 4 小时分散到达，1 份，观察到第 8 小时。
- 高峰：相同文档在前 30 分钟到达，2 份，观察到第 1 小时。
- 批量：相同文档同时到达，1 份，观察到第 1 小时。

每种场景都固定同一组订单、价格和期限，仅改变 FCFS / SJF / 优先级老化 / 期限 / 收入策略。15 组比较各运行两遍，完整 JSON 相同；脚本独立复算设备匹配、无重叠和重复派发、耗时、等待、利用率、收入、成本及闭店结算。

### 全天场景

五种策略都完成 668 单，营业额均为 8550.07 元，超时完成均为 1 单。平均首次等待分别为 FCFS 23.11 秒、SJF 15.07 秒、优先级老化 21.54 秒、期限 18.66 秒、收入 22.04 秒。负载较低且最终都完成时，固定报价使营业额相同；设备选择导致直接成本和利润有小幅差异。

平均首次等待、最大等待和 P95 只包含已经开始的订单，样本数随策略改变。“全部订单观测等待”使用同一批全部订单，未开始订单的等待截止到闭店，仍是有限窗口观测值，不能代表它们之后的完整等待。教材、幻灯片、缓存页数及估算分页的混合样本和 1000 页截断会影响排序及过载程度。这些结果支持该负载下的效率与收入取舍，不能推出某种策略普遍最优。
